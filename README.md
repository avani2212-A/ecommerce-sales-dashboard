Amazon Sales Dashboard

This is a Power BI dashboard I created to analyze and visualize e-commerce sales data.

About the Project

The main goal of this project was to understand sales performance using different business dimensions such as category, market, country, city, and shipping mode.

I used Excel as the source dataset and built an interactive dashboard in Power BI to make the analysis easier to understand.

What I Analyzed
Overall sales and profit
Sales by category
Sales by market
Sales by shipping mode
Profit by city
Country-wise sales
Category-wise sales
Key Metrics

The dashboard shows:

Total Sales
Total Profit
Total Quantity
Total Shipping Cost
Filters

The dashboard includes slicers for:

Category
Ship Mode

These filters can be used to explore the dashboard based on different selections.
